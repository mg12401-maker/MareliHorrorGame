¡INCREÍBLE\! 👻🖤 Ya tenemos una historia bastante completa para nuestro juego.

Objetivo principal seleccionado## Objetivo: Investigar, romper la maldición y escapar

La protagonista tendrá que:

1. Explorar el pueblo abandonado.
2. Investigar documentos y notas sobre el ritual.
3. Encontrar tres objetos sagrados escondidos.
4. Evitar al monstruo mientras busca los objetos.
5. Llegar al santuario japonés.
6. Romper la maldición y encontrar una salida del pueblo.
